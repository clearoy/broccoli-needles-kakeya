Kakeya set definition

A compact set $K\subset\mathbb{R}^2$ is a Kakeya set if it contains a line segment of length $1$ in every direction.

07

Kakeya Conjecture in 2 dimensions

Conjecture Every Kakeya set $K\subset\mathbb{R}^n$ has dimension $n$. $n=2$: Davies 1971 · $n=3$: Wang–Zahl 2025 · $n\ge 4$: open
  1. Setup
    $$0\lt\delta\ll 1,\qquad K_\delta=\{x:\operatorname{dist}(x,K)\lt\delta\}$$

    Pick $1/\delta$ directions $\theta_1,\dots,\theta_{1/\delta}$, spaced $\delta$ apart. The unit segment of $K$ in direction $\theta_i$ thickens to a $\delta\times 1$ tube $T_i\subset K_\delta$.

  2. 1Multiplicity
    $$m(x)=\sum_i \mathbf 1_{T_i}(x)=\#\{i : x\in T_i\},\qquad E=\bigcup_i T_i\subset K_\delta$$
  3. 2Total mass
    $$\int m = \sum_i |T_i| = \frac1\delta\cdot\delta = 1$$
  4. 3Two tubes
    $$|T_i\cap T_j|\approx\frac{\delta^2}{\sin|\theta_i-\theta_j|}\;\lesssim\;\frac{\delta^2}{|\theta_i-\theta_j|+\delta}$$

    The overlap is a parallelogram of height $\delta$ and side $\delta/\sin\theta$. When $\theta\lesssim\delta$ the tubes almost coincide and the overlap is at most $|T_i|=\delta$, hence the $+\delta$.

  5. 4Overlap
    $$\int m^2=\sum_{i,j}|T_i\cap T_j| \;\lesssim\; \sum_i\,\sum_{k=0}^{1/\delta}\frac{\delta^2}{k\delta+\delta} \;=\; \sum_i\,\delta\sum_{k=0}^{1/\delta}\frac{1}{k+1} \;\approx\; \log\tfrac1\delta$$

    Group the pairs by angle $|\theta_i-\theta_j|=k\delta$; the harmonic sum gives the $\log$.

  6. 5Cauchy–Schwarz
    $$1=\Big(\int_E m\cdot 1\Big)^2\le |E|\int m^2 \lesssim |E|\,\log\tfrac1\delta \quad\Longrightarrow\quad |K_\delta|\ge|E|\gtrsim\frac{1}{\log(1/\delta)}$$
  7. 6Count boxes
    $$K\subset\bigcup_{k=1}^{N(\delta)}Q_k \;\Longrightarrow\; K_\delta\subset\bigcup_{k}3Q_k \;\Longrightarrow\; |K_\delta|\le 9\,\delta^2\,N(\delta) \;\Longrightarrow\; N(\delta)\gtrsim\frac{\delta^{-2}}{\log(1/\delta)}$$

    $Q_k$ are boxes of side $\delta$; tripling each one covers the $\delta$-neighbourhood.

  8. Conclusion
    $$N(\delta)\sim\delta^{-d}\;\Longrightarrow\;\delta^{-d}\gtrsim\frac{\delta^{-2}}{\log(1/\delta)}\;\Longrightarrow\;\delta^{\,2-d}\log\tfrac1\delta\gtrsim 1 \text{ as } \delta\to0\;\Longrightarrow\; d\ge 2$$

    If $d\lt 2$, then $\delta^{2-d}\log\frac1\delta\to 0$. And $d\le 2$ for every set in the plane, so $\dim K = 2$.
